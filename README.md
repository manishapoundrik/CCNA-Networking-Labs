# CCNA Networking Labs

A collection of hands-on networking projects focused on network configuration, troubleshooting, and traffic analysis.

## Projects

### Project 1: VLAN and Inter-VLAN Routing

* Technology: Cisco Packet Tracer
* Focus: VLAN configuration and communication between VLANs.
* Folder: `Project-01-VLAN-InterVLAN-Routing/`

### Project 2: Network Traffic Analysis Using Wireshark

* Technology: Wireshark
* Focus: Packet capture, protocol analysis, IP endpoints, TCP/UDP conversations, and network traffic inspection.
* Includes a PDF report, PCAPNG capture file, and analysis screenshots.
* Folder: `Project-02-Network-Traffic-Analysis/`

## Tools and Technologies

* Cisco Packet Tracer
* Wireshark
* TCP/IP networking
* VLANs and Inter-VLAN routing
* IPv4 and IPv6
* TCP and UDP
