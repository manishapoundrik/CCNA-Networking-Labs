# Project 3: Network Access & Security Configuration Lab

## Overview

This project explores network access control and basic security configurations in a simulated Cisco networking environment using Cisco Packet Tracer.

## Objectives

* Practice IPv4 Access Control Lists (ACLs) to permit or deny selected traffic.
* Understand Network Address Translation (NAT) concepts.
* Review secure device-management access and switch security fundamentals.
* Test connectivity and verify the effects of security configurations.

## Tools Used

* Cisco Packet Tracer
* Cisco IOS CLI
* IPv4 ACLs and NAT concepts

## Implementation Plan

1. Create a network topology with routers, switches, and PCs.
2. Assign IP addresses and verify initial connectivity.
3. Configure standard or extended IPv4 ACLs.
4. Apply and test traffic filtering rules.
5. Review NAT and basic device-access security concepts.
6. Document configuration commands and test results.
